# Overview

This repository contains the source code and engineering documentation for a modern, cinematic, scroll-driven 3D portfolio.

The project is designed to demonstrate software engineering, frontend development, UI/UX design, and computer graphics skills through an immersive user experience while maintaining production-level standards for performance, accessibility, maintainability, and scalability.

The portfolio is developed using modern web technologies and follows a comprehensive Engineering Knowledge Base (EKB) that documents every architectural and engineering decision.

# Getting Started

## Prerequisites

Install the following software before starting development.

- Node.js 22+
- npm (or pnpm)
- Git
- Visual Studio Code

Recommended VS Code extensions:

- ESLint
- Prettier
- Tailwind CSS IntelliSense
- Error Lens
- GitLens

---

# Installation

Clone the repository.

```bash
git clone https://github.com/<username>/portfolio.git
```

Move into the project.

```bash
cd portfolio
```

Install dependencies.

```bash
npm install
```

---

# Running the Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# Building for Production

```bash
npm run build
```

---

# Preview Production Build

```bash
npm run start
```
